# 见词 / WordSnap — Pencil 设计参考

## 色彩

```
墨水黑    ■ #0b0b0f   主文字、icon、导航选中
画布白    ■ #f9f9fb   页面底色
纯白      ■ #ffffff   卡片、弹窗、按钮文字
信号蓝    ■ #2f5cff   主品牌色、CTA、激活态、链接
紫雾      ■ #7068f0   辅助强调、复习待复习标记
薄荷      ■ #00c896   已掌握、正向反馈
琥珀闪    ■ #ffa940   拍照/捕捉功能色（唯一暖色，克制使用）
冷灰面    ■ #f0f0f5   Badge 底色、未激活 tab
淡灰边    ■ #e2e2ea   卡片边框、分割线
```

## 字体

| 用在哪 | 字体 | 字重 |
|--------|------|------|
| 单词卡片上的词 | Source Serif 4 | 600 |
| 页面标题 | Inter | 600, -0.02em |
| 释义/按钮/正文 | Inter | 400 |
| 进度数字/统计 | JetBrains Mono | 400 |

## 字号阶梯

```
12  — caption/vbadge
14  — 辅助文字
16  — 正文（默认）
20  — 子标题
24  — 小标题
28  — 单词卡片
32  — 页面标题
40  — 大标题 / 复习页单词
```

## 圆角

```
100px — 按钮（全圆角 pill）
20px  — 卡片
12px  — 输入框 / badge
```

## 间距（基准 4px）

```
4 / 8 / 16 / 24 / 32 / 48 / 64
```

## 层级（不用阴影）

```
底板 #f9f9fb → 卡面 #ffffff + 1px #e2e2ea border → 弹窗 #ffffff + 1px border
```

## 图标

```
线条图标 / 1.5px 描边 / 选中态用信号蓝实心填充
```
