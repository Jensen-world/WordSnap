# 见词 / WordSnap — 产品设计文档 v1

> 一份「随时随地捕捉生词，科学复习不遗忘」的个人词汇银行。
> 不从预设词库出发，以用户真实遇到的词为起点。

---

## 一、产品概述

### 定位

和市面上背单词 App 的核心区别：**你看到的、搜过的、截下来的，才是你要学的。**不以词库取胜，靠个人数据沉淀形成粘性——用得越久，里面的词越贴合你的生活和知识结构，迁移成本越高。

### 命名

| 语言 | 名称 | 含义 |
|------|------|------|
| 中文 | 见词 | 见 = 看见/遇见，双重语义：「见到的词」+「见识一个词」 |
| 英文 | WordSnap | Snap = 快照（拍照捕捉）+ 快速动作（随手记） |

## 二、用户核心路径

### 路径一：拍照录入（现实场景）

适用场景：路上、书里、菜单上看到不认识的词。

1. 首页点拍照按钮（悬浮触发）
2. 对准单词拍照 → 自动 OCR 识别文本
3. 手指框选目标单词
4. 弹窗展示：单词、音标、词性、释义、例句
5. 确认或编辑后一键存入
6. 可选保存原图，作为复习时的记忆锚点

### 路径二：文本录入（手动 / 剪贴板）

适用场景：浏览器、聊天中遇到生词。

1. 复制单词 → App 前台监听剪贴板，弹窗提示存储
2. 也可手动输入
3. 自动补全释义、音标、例句
4. 确认存入

隐私设计：剪贴板内容不上传服务器，纯本地处理。用户可忽略，也可加入白名单 App。

### 路径三：网页剪藏（浏览器插件 / 系统分享）

适用场景：浏览英文网页，整段不理解。

1. 浏览器中选中单词或句子 → 分享 → 存入见词
2. 或通过系统快捷指令一键发送
3. 一段文本送进来 → 自动分词提取生词 → 去重后分别存入
4. 保留原文出处链接

## 三、核心功能

### 1. 单词本

- 卡片列表展示，每张卡片：单词 + 简短释义
- 支持按时间、首字母、掌握程度排序
- 支持标签分类（工作、GRE、旅行、某本书……）
- 支持搜索和筛选（「只显示未掌握」）
- 详情页：音标、词性、多条释义、例句、原图、来源、笔记

### 2. 复习（核心体验）

- 间隔重复（Spaced Repetition），SM-2 改进版
- 复习形式不止一种（见下文优化）
- 用户自我评估：不认识 / 模糊 / 认识
- 每日推送提醒
- 复习会话可随时开始、暂停、继续
- 穿插已掌握词汇防止遗忘

### 3. 拍照 OCR

- 设备端处理：iOS Vision / Android ML Kit，离线可用
- 多词同时识别，逐一点选存入
- 支持裁剪、旋转
- 支持从相册选图

### 4. 剪贴板监听

- 前台运行时监听粘贴板变化
- 检测到英文单词/短语时弹窗
- 白名单机制
- 纯本地，不上传

### 5. 词典与数据源

- 默认接入免费词典 API
- 支持切换词典源
- 用户可自定义释义
- 支持导入/导出（CSV、Anki 格式）

## 四、产品逻辑优化（已确认新增）

以下为讨论确定的优化项，在原构思文档基础上新增。

### 1. 冷启动引导

问题：首次打开词库为空，无价值感。

方案：不做空状态引导文字。改为互动式 onboarding——让用户复制一个最近看到的生词，现场走一遍「存入→查看卡片→复习」闭环，30 秒内感知产品价值。可预置 3-5 个高频词作为种子。

### 2. 重复遇词累积逻辑

问题：同一个词在多个场景遇到，目前方案是存过了就跳过。

方案：改为累积式。同一词再次提交时，不创建新条目，而是把新的来源、原图、语境追加到该词下。复习时展示「这个词，你在 3 个场景里遇到过」，记忆锚点随使用持续丰富。这是和大多数字典 App 的根本差异。

### 3. 复习形式多样化

问题：翻转卡片单一，长期疲劳。

方案：系统自动轮换以下模式——

- 语境回想：展示原图或原文句子，挖掉目标词
- 辨音拼写：播放发音，用户默写
- 选择题：展示释义，四选一

核心原则：原图/原语境必须渗透到复习环节，不只是存在详情页。这是和 Anki 最大的体验差异。

### 4. 短语与搭配处理

问题：实际遇到的往往是短语、搭配、俚语，OCR 拆成多个单字存入体验差。

方案：OCR 识别结果或粘贴内容支持「作为短语整段存入」操作，非强制性，用户可以选拆词或整存。

### 5. 通知设计改为微复习

问题：「你有 12 个词待复习」是功能通知，不是价值通知。

方案：锁屏通知直接展示单词——「ephemeral /ɪˈfemərəl/ — 短暂的」。用户滑掉就是一次微复习，点进去进入完整复习。把每次打扰变成学习机会。

### 6. 录入场景快速跳过

问题：拍照识别了，但发现已经认识这个词，操作摩擦大。

方案：OCR 识别结果增加「跳过/已认识」快捷操作。跳过数据可沉淀为词汇量估算（「你大约认识 8500 个词」），作为未来功能的数据基础。

## 五、信息架构与导航

讨论后调整为三 Tab + 悬浮按钮结构，录入不再占用固定导航位。

```
┌──────────┬──────────┬──────────┐
│   复习    │  单词本   │   我的    │
│ (默认页)  │          │          │
└──────────┴──────────┴──────────┘
                    ┌──────┐
                    │  ＋   │  ← 悬浮按钮（拍照/粘贴/剪藏）
                    └──────┘
```

- **复习 Tab（默认）**：高频场景，打开即复习
- **单词本 Tab**：浏览、搜索、筛选
- **我的 Tab**：设置、词库管理、数据导出、会员
- **录入**：悬浮按钮或长按触发，底部半屏面板弹出三个入口（拍照、粘贴、剪藏）

## 六、设计系统 — Signal Tech

### 设计方向

核心理念：一个 AI 时代的词汇工具，应该像干净的代码或高对比仪表盘——让词本身成为界面唯一的内容，其余全是安静的结构。

参考风格：Linear / Raycast / ChatGPT 的现代 AI 产品美学，轻量于 Officevibe 的 B 端感。Cool but not cold. Clean but not sterile.

### 色彩

| Token | 色值 | 用途 |
|-------|------|------|
| 墨水黑 | `#0b0b0f` | 主文字、icon、底部导航选中态 |
| 画布白 | `#f9f9fb` | 页面底色 |
| 纯白 | `#ffffff` | 卡片、弹窗、按钮文字 |
| 信号蓝 | `#2f5cff` | 主品牌色、CTA 按钮、激活态、链接 |
| 紫雾 | `#7068f0` | 辅助强调、复习待处理标记 |
| 薄荷 | `#00c896` | 已掌握标记、正向反馈 |
| 琥珀闪 | `#ffa940` | 仅用于「捕捉」相关动作（拍照按钮、剪贴板提示）——功能色，非装饰色 |
| 冷灰面 | `#f0f0f5` | Badge 底色、未激活 tab 背景 |
| 淡灰边 | `#e2e2ea` | 卡片边框、分割线 |

### 字体

| 层级 | 字体 | 用途 |
|------|------|------|
| 单词展示 | Source Serif 4 (Display) | 卡片上的单词、详情页标题词——给单词「阅读尊严」，现代编辑感而非纸卷感 |
| 标题 | Inter (SemiBold, tracking -0.02em) | 页面标题、模块标题 |
| 正文/UI | Inter (Regular) | 释义、按钮、导航、所有功能文字 |
| 数字/数据 | JetBrains Mono / SF Mono | 复习统计、单词计数、进度——仪表盘精度感 |

### 形状

| 属性 | 值 |
|------|-----|
| 按钮圆角 | 100px（pill shape） |
| 卡片圆角 | 20px（bento 感） |
| 输入框圆角 | 12px |
| Badge 圆角 | 12px |
| Icon 风格 | Line-icon，1.5px 描边，少量填充仅用于选中态 |
| 阴影 | 不用 box-shadow，用 1px border + 微弱色差区分层级 |
| 间距基准 | 4px |

### 和 Officevibe 参考的关键差异

- Boardroom Navy 太重 → 改用更轻的墨水黑 #0b0b0f，适合移动端持续阅读
- AbcFavoritvariable + Martinaplantijn 太「人味」→ 统一 Inter，单词展示位用 Source Serif 4 做功能区分
- Brand Electric 饱和度过高 → 调至 #2f5cff，大面积使用不刺眼
- 新增薄荷绿 #00c896 作为「已掌握」功能语义色
- 保留琥珀闪但严格限定在「捕捉」动作域，与信号蓝形成功能分界：蓝 = 复习学习，琥珀 = 捕捉录入

## 七、关键产品决策

- **不要用户注册**：第一版本地存储 + iCloud / Google Drive 同步
- **不要社交功能**：唯一社交是分享单词卡到社交媒体作为增长手段
- **不要内置词库**：差异化在于词都是用户自己遇到的
- **基础功能免费**，付费点：OCR 次数、云端同步、高级统计、主题皮肤
- **AI 不做第一版重点**：核心体验在 SRS 复习，后续可用 AI 生成语境短文、分析词汇盲区
