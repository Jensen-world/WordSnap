## 二、策略调整

- **查词策略**：LLM 优先，ECDICT 离线兜底，缓存命中直接返回
- **释义精简**：只展示 LLM 返回的首条精确释义，不再显示全部 ECDICT 词条
- **缓存策略**：仅 LLM 成功结果缓存，ECDICT 兜底结果不缓存（防止缓存污染）
- **学习计划配额**：增加 `.clamp()` 上限封顶，配额不超过实际可用词数

## 三、Bug 修复

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | 新词没有例句 | ECDICT 兜底结果被写入缓存，同一单词永远不再调 LLM | 移除 ECDICT 路径的 `_putCache()` |
| 2 | LLM 连接失败无法诊断 | 所有错误静默吞掉 `catch (_) { return null; }` | 每个失败点加 `print()`；新增 `testConnection()` 返回具体错误 |
| 3 | 新装 APP 学习计划显示 10/1/10 | 配额未封顶到实际可用词数 | 加 `.clamp(0, dbNewCount)` / `.clamp(0, dbReviewCount)` |
| 4 | 设置页测试连接信息不明确 | 用 `lookup('hello')` 测试，错误被吞 | 改用 `testConnection()`，显示具体 HTTP 状态码 |

## 五、横板字体 Logo 设计

参考 `字母样式.png` 设计稿，用 Python/Pillow 像素级着色生成 wordmark：
- `w` 区域 → 品牌蓝 `#2F5CFF`
- `ordsnap` 区域 → 墨黑 `#0B0B0F`
- `p` 反色区 → 橙色 `#FFA940`

**6 轮脚本迭代：**
| 脚本 | 功能 |
|------|------|
| `analyze_letters.py` | 分析字母边界和 p counter 坐标 |
| `generate_wordmark.py` ~ `v4.py` | 4 轮迭代优化颜色和填充 |
| `render_wordmark_final.py` | 最终渲染：颜色替换 + 椭圆叠加 + 透明背景 |
| `render_wordmark_clean.py` | 重写版：自动检测 p bowl 区域 |
| `use_user_wordmark.py` | 处理用户 PS 精修版，白底转透明 |

**横板 Logo：**
- `横板logo.png`：水平布局版本
- `横板logo.psd`：Photoshop 源文件
- 最终采用用户 Photoshop 精修版（反锯齿优于程序化渲染）
