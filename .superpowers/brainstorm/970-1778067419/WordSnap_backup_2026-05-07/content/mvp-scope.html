MVP 范围：功能优先级排序

确定了 Flutter，现在需要定第一版做什么、分几个阶段

我的建议：三阶段交付

P0 · MVP 核心闭环

目标：1-2 周跑通「录入 → 存储 → 复习」

  • 手动文本录入 — 输入单词 → 查词典 → 存入
  • 剪贴板监听 — 前台检测英文 → 弹窗存入
  • 单词本 — 卡片列表 + 详情页（音标/释义/例句）
  • SRS 复习 — 翻转卡片模式（最简版，SM-2 算法）
  • 本地 SQLite — 纯本地存储，无网络依赖
  • 设计 Token 落地 — Signal Tech 主题系统

不含：拍照 OCR、Cloud Sync、推送通知

P1 · 核心体验升级

目标：区别化体验 + 录入丰富化

  • 拍照 OCR — ML Kit 集成 + 框选单词 + 词组整存
  • 复习多样化 — 语境回想 / 辨音拼写 / 选择题轮换
  • 重复遇词累积 — 同词多场景附加来源/原图
  • 微复习通知 — 锁屏显示单词，滑掉即复习
  • 冷启动引导 — 互动式 onboarding + 3-5 个种子词
  • 标签与筛选 — 分类、搜索、「只显示未掌握」

不含：浏览器插件、Cloud Sync、数据导出

P2 · 生态扩展

目标：增长 + 跨平台

  • 浏览器插件 — Chrome Extension 剪藏单词
  • 云端同步 — Google Drive / iCloud 备份恢复
  • 数据导出 — CSV / Anki 格式
  • 词汇量统计 — 基于跳过数据的词汇估算
  • 分享单词卡 — 社交增长
  • 付费功能 — OCR 次数限制 / 高级统计 / 主题皮肤

词典 API 选择

文档要求"默认接入免费词典 API"，推荐：

Free Dictionary API

api.dictionaryapi.dev — 免费，无需 Key，英文词典，有音标+释义+例句

备用：Datamuse

api.datamuse.com — 免费，关联词+语境例句丰富
